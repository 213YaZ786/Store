# Store

Installs and updates the 213YaZ786 apps from their GitHub releases. No account, no tracking.

Credits: App Manager (https://github.com/MuntashirAkon/AppManager, GPL-3.0) through the install kit, so Store is GPL-3.0. GrapheneOS App Store (https://github.com/GrapheneOS/AppStore, MIT): the install flow, the retried catalogue, the resumed download, the live list. kotlin-retry (https://github.com/michaelbull/kotlin-retry, ISC): the retry. Icons: Material Symbols, Apache License 2.0.
